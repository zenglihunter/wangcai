Cloudflare Log Query

Query Cloudflare CDN/WAF request analytics for a zone or hostname through the bundled GraphQL script. Use when the user asks to查看 CDN/Cloudflare 日志, 拉取昨天/今天/最近几小时的请求概览, 分析异常流量, 查看 Top IP/Top Path/状态码/安全动作, 排查 403/404/5xx, 或继续深挖某个可疑 IP 的访问明细。
